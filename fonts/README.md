# Fonts

**ArmOS Mono** is the console and boot-screen font. It is a bitmap version of
Cascadia Mono and Cascadia Code (Copyright (c) 2019 - Present, Microsoft
Corporation), baked at 25 px and 22 px by `tools/make_font.py` into
`kernel/font.dull`.

Cascadia is licensed under the SIL Open Font License 1.1, which also covers ArmOS
Mono; the full license is in [OFL-cascadia.txt](OFL-cascadia.txt). The license
reserves the name "Cascadia Code", so the baked version is called ArmOS Mono.
